Install

  1. Windows: extract the ZIP, move roxy.exe to a folder your account can write (for example %LOCALAPPDATA%\Programs\ROXY), then run it.
  2. Linux: chmod +x roxy-linux && ./roxy-linux
  3. Open Models, connect an API provider or install an agent CLI, then pick a model in the composer.
# Linux, one line
curl -fL -o roxy roxy-linux && chmod +x roxy && ./roxy
Updates happen in the app. ROXY checks for a new release at launch and shows a progress bar while it downloads and installs — no terminal window, no manual download. Manual check: Settings → About.
Windows publisher. Builds are currently unsigned, so Windows cannot show a verified publisher and SmartScreen may warn. Verify the checksum below before running, and only bypass a warning if you trust the source.

PowerShell: Get-FileHash .\roxy-windows-x64.zip -Algorithm SHA256 · Linux: sha256sum roxy-linux
